Représentation de Fresnel dynamique (construction bout à bout, axe des phases φ = 0 porté par u)

Chaque grandeur sinusoïdale est un vecteur de longueur égale à son amplitude, tournant à ω = 2πN. L'axe des phases (φ = 0) est porté par la tension du GBF u(t) = Um·sin(ωt). On place bout à bout : UR = R·Im (même direction que i, faisant l'angle Δφi avec l'axe), puis UL = Lω·Im (+π/2 par rapport à i), puis UC = Im/(Cω) (−π/2 par rapport à i). 1. Mise en équation

Loi des mailles avec i(t) = Im·sin(ωt + φi) :

u = R·i + L·di/dt + (1/C)∫i dt

Chaque terme devient un vecteur (module ; phase par rapport à i) :

  • R·i : (R·Im ; 0)
  • L·di/dt : (Lω·Im ; +π/2)
  • (1/C)∫i dt : (Im/Cω ; −π/2)

Mis bout à bout, ils ont pour résultante Um, de phase nulle (axe de u). Les phases de ces trois vecteurs par rapport à u valent donc Δφi, Δφi + π/2 et Δφi − π/2, avec Δφi = −φ.

2. Z, Im, UCm et φ par le théorème de Pythagore

Dans la construction bout à bout, UL et UC sont colinéaires et de sens opposés : le triangle (UR ; UL − UC ; Um) est rectangle :

Um² = (R·Im)² + (Lω·Im − Im/Cω)²
Z = Um/Im = √( R² + (Lω − 1/Cω)² )
Im = Um/Z
UCm = Im/(Cω) = Um / (Cω·Z)
tan φ = (Lω − 1/Cω)/R ; cos φ = R/Z

φ = φu − φi est l'angle entre i et Um dans le diagramme ; Δφi = −φ est celui utilisé dans le simulateur.

3. Résonance d'intensité

Im = Um/Z est maximale quand Z est minimale, c'est-à-dire quand UL et UC se compensent (vecteurs opposés, de même longueur) :

Lω₀ = 1/(Cω₀) ⟹ N₀ = 1/(2π√(LC))
  • Z = R (minimale) ; Im0 = Um/R (maximale)
  • φ = 0 : u et i sont en phase (circuit résistif)
  • UR = Um ; ULm = UCm = Q·Um
  • Surtension aux bornes de C et de L si Q > 1
  • Largeur de la bande passante à −3 dB (Im ≥ Im0/√2) : ΔN = N₂ − N₁ = R/(2πL) = N₀/Q

4. Résonance de charge (de UCm)

La charge est q = C·uC, donc qm = C·UCm et la résonance de charge est celle de UCm. On étudie :

UCm = Um / √( C²R²ω² + (LCω² − 1)² )

UCm est maximale quand g(x) = C²R²x + (LCx − 1)², avec x = ω², est minimale. Condition g′(x) = 0 :

ωr² = 1/(LC) − R²/(2L²) = ω₀²(1 − 1/(2Q²))
Nr = N₀·√(1 − 1/(2Q²)) < N₀
UCm,max = Q·Um / √(1 − 1/(4Q²))
  • Elle n'existe que si Q > 1/√2 ≈ 0,707 ; sinon UCm décroît à partir de Um (N = 0).
  • À Nr, le circuit est capacitif : tan φ = −R/(2Lωr).
  • Pour Q grand, Nr ≈ N₀ et UCm,max ≈ Q·Um.

5. Effet inductif, résistif ou capacitif

Il dépend du signe de X = Lω − 1/Cω (ligne active en surbrillance) :

EffetConditionFresnelPhase
InductifN > N₀ : Lω > 1/CωUL > UC : i sous l'axe de uφ > 0 : u en avance sur i
RésistifN = N₀ : Lω = 1/CωUL = UC : i sur l'axe de uφ = 0 : u et i en phase
CapacitifN < N₀ : Lω < 1/CωUC > UL : i au-dessus de l'axe de uφ < 0 : u en retard sur i

Limites : N → 0, φ → −π/2, Z → ∞, UCm → Um ; N → ∞, φ → +π/2, Z → ∞, UCm → 0.

6. Expressions du facteur de surtension (ou de qualité) Q

À la résonance d'intensité (valeurs calculées pour les réglages actuels, toutes égales) :

Interprétation énergétique : Q = 2π · (énergie maximale emmagasinée) / (énergie dissipée par effet Joule en une période). Q grand : résonance aiguë, circuit sélectif.

Déphasage φi - φu

Déphasage de l'intensité i(t) par rapport à u(t), avec u pour référence (φu = 0) :

Δφi = arctan(-(Lω - 1/Cω) / Rtotal) rad

À la résonance d'intensité (N = N₀) : Δφi = 0 rad.

Déphasage φuc - φu

Comme uC(t) est en retard de π/2 rad sur i(t) :

Δφuc = Δφi - π/2 rad

À la résonance d'intensité : Δφuc = -π/2 rad (-1.57 rad).
